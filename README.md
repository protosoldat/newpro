# Calculadora de Interés Simple

Este es un proyecto que contiene un script en Bash para calcular el interés simple. El propósito de la calculadora es obtener el interés generado por un capital inicial durante un período de tiempo a una tasa de interés anual fija.

## ¿Cómo funciona?
El script solicita al usuario tres datos de entrada:
- **p (principal):** El capital inicial.
- **t (time):** El período de tiempo en años.
- **r (rate):** La tasa de interés anual.

La fórmula utilizada para el cálculo es:
`interés simple = (p * t * r) / 100`
